# Rafael

Rafael is an AI desktop assistant by Automatika. This repository holds **installers and release notes only**.
The source code is private.

## Download

Get `RafaelSetup.exe` from the [latest release](https://github.com/automatika-usa/rafael-releases/releases/latest).
Each release also has `RafaelSetup.exe.sha256`; installed copies of Rafael check it before applying an update.

## System requirements

Short version: **Windows 10 (2004) or Windows 11, 64-bit, 2 CPU cores, 4 GB RAM, 3 GB free disk.**
8 GB RAM and 4 cores are recommended. macOS is not available yet.

The installer checks your PC before installing, and Rafael turns off heavy features (3D background, hand
gestures, on-PC speech-to-text, camera tracking, local AI) on PCs that can't run them well.
Full details: [SYSTEM_REQUIREMENTS.md](SYSTEM_REQUIREMENTS.md).
